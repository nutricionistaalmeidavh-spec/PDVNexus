# PDV Nexus — geração licenciada v2

- Clientes já instalados permanecem no canal `latest.json`, congelado em **2.0.0**.
- Novas instalações a partir de **2.1.0** usam `latest-v2.json`.
- Um novo release sempre publica os dois manifests; o legado nunca aponta para a geração licenciada.
- Instalar manualmente 2.1+ é uma migração voluntária e passa a exigir ativação.
- O banco local não deve ser migrado antes de a licença v2 ser validada.
